# NasFinder Android 오픈 소스 구성요소

NasFinder Android는 아래 오픈 소스 구성요소를 사용합니다. 정확한 적용 버전은
[`app/build.gradle.kts`](../app/build.gradle.kts)를 기준으로 합니다.

| 구성요소 | 용도 | 라이선스 | 공식 소스 |
| --- | --- | --- | --- |
| OkHttp | HTTP·WebDAV 통신 | Apache License 2.0 | [square/okhttp](https://github.com/square/okhttp) |
| JSch (mwiede fork) | SFTP·SSH 통신 | BSD-3-Clause | [mwiede/jsch](https://github.com/mwiede/jsch) |
| SMBJ | SMB 파일 통신 | Apache License 2.0 | [hierynomus/smbj](https://github.com/hierynomus/smbj) |

각 구성요소의 저작권과 이용 조건은 연결된 공식 저장소의 LICENSE 및 NOTICE를 따릅니다.
